ENتواصل معي

أهلاً بك، أنا

محمد صبحي "مطور واجهات أمامية محترف متخصص في بناء مواقع عالية الأداء وتجربة مستخدم مثالية."

أقوم بتصميم وبناء مواقع إلكترونية حديثة تجمع بين التصميم الأنيق، السرعة، وسهولة الاستخدام لمساعدة البراندات على النمو رقمياً.

تواصل معي

ماذا أفعل؟

"أساعد الشركات الناشئة والمشاريع الصغيرة على بناء حضور رقمي قوي من خلال تطوير واجهات Front-end تجمع بين دقة التصميم وسرعة الأداء. مهمتي هي تحويل الأفكار الطموحة إلى واقع ملموس في وقت قياسي، مع الالتزام بأعلى معايير الجودة."

من أنا

اسمي محمد صبحي، مطور واجهات أمامية متخصص في تحويل التصاميم المعقدة إلى مواقع ويب تفاعلية ومتجاوبة بالكامل.

الخبرة

خبير في حلول الويب عالية الأداء. بفضل خبرتي، أدعم الشركات الناشئة بـ:

  • كود نظيف: تطوير قابل للتوسع وسهل الصيانة.

  • تصميم UI/UX: واجهات عصرية تركز على المستخدم.

  • تجاوب كامل: متوافق مع كافة الشاشات والأجهزة.

  • سيو تقني: مهيأ للسرعة ومحركات البحث.

الخدمات

تطوير المواقع

"أبني مواقع حديثة ومتجاوبة باستخدام أحدث التقنيات لتقديم تجربة ويب سريعة واحترافية تلبي تطلعات عملائك."

أمثلة:

  • مواقع الشركات
  • بورتفوليو شخصي
  • مواقع خدمية

صفحات الهبوط (Landing Pages)

تصميم صفحات هبوط جذابة تهدف لتحويل الزوار إلى عملاء فعليين بأعلى معدلات التحويل.

أمثلة:

  • صفحات هبوط للمنتجات
  • صفحات الحملات التسويقية
  • صفحات الشركات الناشئة

تحويل التصميم لكود (Figma / PSD to HTML)

تحويل تصاميم UI/UX إلى مواقع ويب حقيقية متجاوبة بدقة بيكسل مثالية وكود منظم.

أمثلة:

  • تحويل Figma إلى HTML
  • تحويل PSD إلى HTML
  • تصميم متجاوب بالكامل

خدمات إضافية

تطوير وتحسين المواقع

أساعد في تطوير المواقع الحالية عبر تحديث شكلها، تحسين الوظائف، ومعالجة أي مشاكل تقنية.

أمثلة:

  • إعادة تصميم المواقع
  • إضافة أقسام جديدة
  • إصلاح مشاكل الـ Front-end

تصميم الشعارات

أصمم شعارات عصرية وفريدة تمثل هوية البراند بشكل احترافي وجذاب.

أمثلة:

  • تحسين الصور
  • تحسين الكود
  • تسريع الصفحات

المهارات التقنية

HTML

أستخدم HTML لبناء هيكل المواقع وتنظيم المحتوى بشكل دلالي ومنظم (Semantic HTML) لضمان أفضل أداء وتوافق.

CSS

أصمم واجهات عصرية ومتجاوبة بالكامل باستخدام CSS لضمان مظهر جذاب وتجربة مستخدم سلسة على كافة الأجهزة.

JavaScript

"أقوم ببناء تطبيقات ديناميكية باستخدام JavaScript (ES6+) والتعامل الاحترافي مع الـ APIs لضمان تفاعل سريع وتجربة مستخدم تفاعلية."
